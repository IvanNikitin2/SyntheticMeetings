# Synthetic Meetings

Generates synthetic meeting audio from a YAML preset. The LLM writes
a realistic conversation directly as Azure-compatible SSML. Azure Neural TTS synthesizes
each speaker turn individually, then PyDub merges all turns into a final audio file.

---

## Requirements

- Python 3.10+
- [ffmpeg](https://ffmpeg.org/download.html) — required by PyDub for MP3 export
- An Anthropic or OpenAI API key
- An Azure Speech resource (key + region)

---

## Setup

```bash
git clone <repo-url>
cd SyntheticMeetings

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install -r requirements.txt

cp .env.example .env
# Edit .env and fill in your API keys
```

---

## Configuration

### `.env`

```ini
# Set ONE LLM key. Anthropic is checked first.
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=

AZURE_TTS_KEY=your-azure-key
AZURE_TTS_REGION=eastus
```

### Preset YAML

Copy and edit the example preset:

```bash
cp presets/startup_standup.yaml presets/my_meeting.yaml
```

Open `presets/startup_standup.yaml` — every field is documented with inline comments.

---

## Usage

```bash
python3 main.py presets/startup_standup.yaml
python3 main.py presets/my_meeting.yaml --output-dir /tmp/meetings
```

---

## Output

Each run produces a folder at `output/YYYY-MM-DD_<preset_name>/`:

```
output/2026-05-22_startup_standup/
├── meeting.ssml          # Full Azure SSML generated by the LLM
├── transcript.txt        # [Name]: text — one line per speaker turn
├── speakers/
│   ├── turn_001_Alex.wav
│   ├── turn_002_Sara.wav
│   └── ...
├── merged_meeting.wav    # All turns concatenated
└── merged_meeting.mp3    # Same, MP3 encoded
```

## Troubleshooting

| Error | Fix |
|---|---|
| `no LLM API key found` | Set `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` in `.env` |
| `AZURE_TTS_KEY is not set` | Add your Azure Speech key to `.env` |
| `failed to export MP3` | Install ffmpeg and ensure it is in your PATH |
| `LLM returned invalid XML` | The LLM produced malformed SSML — re-run; if persistent, simplify your preset |
| `preset validation failed` | Check the error field names against the preset schema in `presets/startup_standup.yaml` |
